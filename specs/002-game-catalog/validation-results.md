# Game Catalog Validation Results

**Date**: 2026-09-26
**Feature**: 002-game-catalog
**Spec**: [spec.md](./spec.md)
**Quickstart**: [quickstart.md](./quickstart.md)

This run validates the **as-shipped** design: a shell script generated by `ScriptService`
authenticates to Keycloak via the **Device Authorization Grant** and POSTs a directory listing
(plus Steam manifest contents) to `POST /api/gamecatalog/ingest/scan`; the backend parses it with a
`LibraryParser` and reconciles.

It **supersedes the 2026-08-05 run**, which validated the earlier Python sidecar
(`gamecatalog-sync-service`) + static bearer-token design. That design was replaced by
`V20260806__gamecatalog_scan_redesign.sql`; there is no sidecar and no static token any more.

### Bugs the new coverage exposed and fixed

| Bug | Fix |
|-----|-----|
| `ScriptService` blanked the template's own bash expansions (`host=${host%%.*}`), so `detect_hostname` produced an empty hostname and the script always exited (T027) | Unknown `${...}` placeholders now pass through untouched |
| EmuDeck title normalization double-escaped its bracket replacement, leaving `[!]`-style tags in titles (FR-009) | Replaced the literal `\[` with a real `[` |
| `NO_CHANGE` idempotency was dead — the payload hash covered `capturedAt`, which the script sets fresh on every run | Hash the listing + manifest contents only |
| `ResilientAiService` logged the per-module model as a label but sent the global model; gamecatalog's label (`claude-sonnet-4-20250514`) was rejected by the API (T014) | Send the module model as `AnthropicChatOptions` on the per-call prompt; corrected the label to `claude-sonnet-5` |

## Notes / follow-ups

- **Testcontainers on Podman**: tests need `DOCKER_HOST` pointed at the Podman machine socket
  (`podman machine inspect --format '{{.ConnectionInfo.PodmanSocket.Path}}'`) and
  `TESTCONTAINERS_RYUK_DISABLED=true`. Documented in `README.md` and `jordylab-be/AGENTS.md`.
- **agent-browser interaction**: `agent-browser click` on Keycloak's login/consent buttons did not
  trigger form submission in this environment; `agent-browser eval` with a direct
  `form.submit()` / `button.click()` worked reliably. Navigation was done with `open <url>`.
- **Quickstart rewritten** for the shipped script design (it previously described the sidecar).
