Family library

Paste a short-lived Steam access token (about 24 hours). It is used for one sync and never stored.

How do I get a token?
  1. In a browser, sign in to the Steam store at store.steampowered.com (being signed in to the Steam app is not enough).
  2. In the same browser open the Steam Points Summary config page. It shows a line of text with a long webapi_token value.
  3. Select all of that text, copy it and paste it above — the whole page works, JordyLab picks the token out.

If the page only shows "data":[], this browser is not signed in to the Steam store: sign in, then reload the page. The token expires roughly every 24 hours — paste a fresh one to sync again. This uses Steam's undocumented family API; see the family API reference.
