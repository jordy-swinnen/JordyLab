Family library

Paste a short-lived Steam access token (about 24 hours). It is used for one sync and never stored.

How do I get a token?
  1. In a browser, sign in to your Steam account.
  2. Open the Steam Points Summary config page.
  3. Copy the webapi_token value (a long string) and paste it above.

The token expires roughly every 24 hours — paste a fresh one to sync again. This uses Steam's undocumented family API; see the family API reference.
